## Before contacting support

1. Note your OS version and Perpetua version (About / `tauri.conf.json`).
2. Confirm whether the issue is vault data, keep-alive reminders, or Pro
   activation (Polar vs offline key).
3. Prefer exporting a **redacted** vault sample (remove license keys) if
   asked to reproduce a data issue.

## Polar purchases

Activation uses Polar customer-portal / organization configuration baked at
release build time. If activation fails, include the order reference (not
the full license key) when emailing support.
